# Student Study Planner

A Python-based command-line application that helps students organise their study tasks, track deadlines, and monitor their progress.

## Features

- Add new tasks with a subject and deadline.
- View all saved tasks.
- Mark tasks as completed.
- Delete tasks with confirmation.
- Search tasks by subject.
- Filter tasks by status (Pending or Completed).
- Automatically save and load tasks using JSON.

## Technologies Used

- Python
- JSON for data storage
- Git and GitHub for version control

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

   `python main.py`

## How It Works

The application provides a menu where users can add, view, update, delete, search, and filter tasks.

Each task contains a name, subject, deadline, and completion status.

Tasks are stored locally in a JSON file so that they remain available after restarting the program.
